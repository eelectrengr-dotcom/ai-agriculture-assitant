# 🌱 AI Agriculture Assistant

An end-to-end machine learning system that combines four intelligent models — **Crop Recommendation**, **Fertilizer Recommendation**, **Crop Yield Prediction**, and **Plant Disease Detection** — into one unified platform, deployed as both a **Streamlit dashboard** and a **FastAPI backend**.

## 📋 Overview

This project was built as a capstone to demonstrate a complete, production-style ML workflow — from raw data to a deployed, user-facing application. It covers four real-world agriculture problems in a single system:

| Module | Problem Type | Model Used |
|---|---|---|
| 🌾 Crop Recommendation | Multi-class classification | XGBoost |
| 🧪 Fertilizer Recommendation | Multi-class classification | XGBoost |
| 📈 Crop Yield Prediction | Regression | LightGBM |
| 🍃 Disease Prediction | Image classification | CNN (TensorFlow/Keras) |

---

## ✨ Features

- Predicts the best crop to grow based on soil nutrients (N, P, K), temperature, humidity, pH, and rainfall
- Recommends the right fertilizer based on soil type, crop type, and nutrient levels
- Estimates crop yield (hg/ha) based on region, crop, year, rainfall, pesticide use, and temperature
- Detects plant leaf disease from an uploaded image using a trained CNN
- One-click example buttons on every module for instant testing
- Session-based prediction history with CSV export
- Downloadable per-prediction text reports
- Fully working REST API (FastAPI) alongside the interactive dashboard (Streamlit)
- Custom-built, dependency-free API test page (no external CDN required)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/AI-Agriculture-Assistant.git
cd AI-Agriculture-Assistant
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Get the datasets
All datasets (crop, fertilizer, yield CSVs + disease leaf images) are packaged together in `data.rar`, included in this repository.

1. Download `data.rar` from this repo
2. Extract it into the project root so you end up with:
```
AI-Agriculture-Assistant/
└── data/
    ├── Crop_recommendation.csv
    ├── Fertilizer_Prediction.csv
    ├── yield_df.csv
    └── disease_data/
        ├── Potato___Early_blight/
        ├── Potato___healthy/
        └── Potato___Late_blight/
```

> Original dataset sources are also listed in the [Datasets Used](#-datasets-used) section below, if you'd prefer to download them fresh from Kaggle instead.

### 4. Train the models
```bash
python train.py
```
This creates a `models/` folder containing all 4 trained models and their label encoders.

### 5. Run the Streamlit dashboard
```bash
streamlit run app.py
```
Opens automatically at `http://localhost:8501`

### 6. Run the FastAPI backend
```bash
uvicorn api:app --reload --port 8080
```
- API root: `http://127.0.0.1:8080/`
- Interactive test dashboard: `http://127.0.0.1:8080/test`
- Health check: `http://127.0.0.1:8080/health`

## 🔌 API Endpoints

| Endpoint | Method | Description |
|---|---|---|
| `/predict/crop` | POST | Returns the recommended crop |
| `/predict/fertilizer` | POST | Returns the recommended fertilizer |
| `/predict/yield` | POST | Returns predicted yield (hg/ha) |
| `/predict/disease` | POST | Accepts an image, returns predicted disease + confidence |
| `/health` | GET | Confirms the API and all models are loaded |
| `/test` | GET | Built-in interactive dashboard for testing all endpoints |
